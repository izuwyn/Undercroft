# The Undercroft: releases

Windows builds of The Undercroft, and `latest.json`, which the game's **Check for updates** button reads.

Latest: **v0.11**. Download [`releases/TheUndercroft-v0.11-win64.exe`](releases/TheUndercroft-v0.11-win64.exe)
and double-click it. It isn't code-signed, so Windows SmartScreen may warn on first launch: choose
**More info → Run anyway**. From then on the game can update itself from the title screen.
